# Friburgo Bus

Horários da FAOL + rastreamento Merus Tracker (Partiu) para Nova Friburgo - RJ.

## Gerar o APK
1. Suba todos os arquivos deste projeto para um repositório no GitHub (branch `main`).
2. Abra a aba **Actions** > **Build Android APK** (roda sozinho a cada push; ou clique em *Run workflow*).
3. Ao terminar, baixe o artefato **app-debug-apk** (contém `app-debug.apk`) e instale no celular.

## Se algo vier vazio
Abra a aba **Diagnóstico** no app: ela mostra status HTTP, tempo e JSON/HTML bruto de cada rota.
