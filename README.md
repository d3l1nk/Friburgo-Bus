# Friburgo Bus v1.1

Horários da FAOL + rastreamento Merus Tracker (Partiu) para Nova Friburgo - RJ.

## Gerar o APK
1. Substitua os arquivos do seu repositório pelo conteúdo deste projeto (branch `main`).
2. Aba **Actions** > **Build Android APK** (roda a cada push, ou *Run workflow*).
3. Baixe o artefato **app-debug-apk** (`app-debug.apk`) e instale.

## Se algo vier vazio
Aba **Diagnóstico**: status HTTP, tempo, JSON/HTML bruto e versão normalizada de cada rota.
